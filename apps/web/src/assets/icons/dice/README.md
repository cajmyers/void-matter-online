# Attack die icon

Used on asset cards: one icon per attack die in the weapon row (`AttackDieIcon`).

Optional owner bitmap (transparent glyph on dark, like action icons):

| File | Use |
|------|-----|
| `attack.png` | Replaces the built-in SVG when present (150×150 or similar) |

Until a file exists, the UI uses the inline SVG gear.
